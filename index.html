About this site¶

Linkawho? is inspired by Jerry's Guide to the World Wide Web, the hand-curated directory that later became Yahoo!. Like the original guide, Linkawho? aims to help people discover interesting and useful corners of the Internet through human curation rather than algorithms.

Search engines and Web Indexes¶

  • DuckDuckGo - More privacy-respecting Google alternative using Bing search results.
  • DuckDuckGo Lite - DuckDuckGo but very lightweight. (SIDENOTE: Great for slow connections!)

  • DuckDuckGo HTML - DuckDuckGo but in plain HTML.
  • LinkAWho Legacy - LinkAWho for old sites for PCs and sites for old PC targeting projects.
